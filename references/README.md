# references/

Thư mục chứa **tài liệu tham khảo** (không phải code chạy): mẫu kịch bản, ảnh sản phẩm mẫu, tài liệu API của nhà cung cấp, ví dụ video tham khảo...

Quy ước:

- Không đặt secret, token, cookie hay dữ liệu cá nhân vào đây.
- Dữ liệu mẫu phải ghi rõ nguồn và đánh dấu `DEMO` trong tên file hoặc README con.
- File lớn (video, ảnh gốc) nên lưu ở MinIO thay vì commit vào git.
